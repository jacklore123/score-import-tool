# 数据格式说明

## 原始成绩表

至少需要包含两列：

- 姓名列：默认查找“姓名”。
- 成绩列：默认查找“成绩”“分数”“总分”“得分”。

常见科目也可以直接配置，例如：

- 语文
- 数学
- 英语
- 物理
- 历史

程序兼容两级表头，例如“物理 / 分数”。

## 系统模板

系统模板由综合评价系统导出。程序会保留模板中的其他列，只写入配置的成绩列。

## 缺考识别

以下情况视为缺考：

- 空单元格
- `缺考`
- `/`、`／`、`\`
- `-`、`—`
- NaN

## 成绩处理

- 文本数字会自动转为数值，例如 `"120"` → `120`。
- 小数会保留，例如 `100.5`。
- `0` 会正常保留，不会被当成缺考。
