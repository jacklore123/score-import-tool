# 使用说明

## 一、准备文件

### 原始成绩表

可以来自五岳、好分数等平台，支持：

- `.xlsx`
- `.xls`
- `.zip`
- 包含上述文件的文件夹

程序会自动筛选真正包含“姓名”和“成绩”列的表格。

### 系统模板

请从广西综合评价系统下载成绩导入模板，通常为 `.xlsx`。

## 二、运行程序

```powershell
python main.py
```

## 三、界面操作

1. 左侧“原始成绩表”添加原始文件或文件夹。
2. 右侧“系统表格”添加系统模板文件或文件夹。
3. 默认按学生名单自动配对，文件名可以不同。
4. 如有特殊表头，可修改“姓名列名 / 成绩列名 / 备注列名”。
5. 选择导出文件夹。
6. 点击“开始匹配”。

## 四、匹配规则

- 按“姓名”精确匹配。
- 未匹配到的学生：成绩留空，备注写“缺考”。
- 缺考、空值、`/`、`-` 等标记会被识别为缺考。
- 同一学生出现多次时会给出警告，但程序会采用第一条成绩。

## 五、输出

程序会生成：

- 标准原始成绩表
- 已填入成绩的系统模板

输出文件名带时间戳，不会覆盖旧文件。
